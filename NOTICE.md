## Fonts

Fonts are fetched from <https://github.com/google/fonts> and baked into static
instances by `tools/fetch_fonts.py`. Per-skin attribution, upstream paths,
instancing axes and SHA-256 digests are recorded in each skin's `FONTS.md`, and
the upstream licence text ships alongside the fonts in each skin's `fonts/`
directory as the SIL Open Font License requires.

| Family | Licence | Used by |
|---|---|---|
| Roboto | SIL OFL 1.1 | `skin.cable.tv` |
| Noto Mono | SIL OFL 1.1 | `skin.cable.tv` (inherited from Estuary) |
| Jost\*, Open Sans | SIL OFL 1.1 | `skin.cable.retro` |
| Inter | SIL OFL 1.1 | `skin.cable.stream` |

Note that Roboto moved from the Apache-2.0 licensed `apache/roboto/` path to the
OFL licensed `ofl/roboto/` path upstream, and is now published as a variable
font only.
